# LES-jordan_solver
Для сборки программы используется утилита `make` (открыть терминал в нужной папке, ввести 'make')
Перед этим скачать все файлы отсюда в одну папку.


Компиляция выполняется с флагами максимальной оптимизации -O3, строгой проверки предупреждений -Wall -Wextra по стандарту C99 с линковкой математической библиотеки -lm. В результате создается исполняемый файл a.out


Для удаления файлов .o ввести в терминале 'make clean';


Запуск программы для тестов: ./a.out n m k, где n - размерность матрицы коэффициентов, m - кол-во строк и столбцов, которое будет выведено на экран, k - способ задания матрицы коэф


если k=0, ввести еще [filename], т.к матрица коэф считывается из файла

Программа реализует метод Жордана для решения СЛАУ. В столбце выбирается ведущий элемент a(ij) (макс по модулю, но при наших способах задания матрицы у нее все элементы неотрицательные), когда такую строчку нашли, она переставляется с текущей, далее строка делится на этот элемент (нормируется), после чего из строк выше и ниже вычитается с подходящим коэф-м, чтобы обнулить столбец j.
В результате матрица коэф-в станет единичной, а столбец правой части b(i) станет решением СЛАУ (с этим столбцом делали тоже самое, что и с соответствующей i строчкой)

Также программа считает время работы алгоритма Жордана, невязку и разницу между теоретическим ответом и полученным.
